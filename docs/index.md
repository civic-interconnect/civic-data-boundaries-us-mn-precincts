# Minnesota Precinct Boundaries

Documentation for `civic-data-boundaries-us-mn-precincts`.

This package provides a reproducible pipeline for downloading, normalizing,
validating, indexing, and publishing official Minnesota precinct boundary data.

## Current Snapshot

- Source: Minnesota Secretary of State statewide precinct GeoJSON
- Source date: `2026-05-01`
- Snapshot version: `2026-05`

Snapshot version and date are derived automatically from the source metadata.

## Installation

```shell
uv add civic-data-boundaries-us-mn-precincts
```

Or:

```shell
pip install civic-data-boundaries-us-mn-precincts
```

## Usage

Refresh the current Minnesota precinct snapshot:

```shell
civic-us-mn refresh
```

See the API Reference for package modules and functions.
